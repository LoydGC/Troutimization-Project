# Assumptions register

Every modeling assumption and judgement call the final model depends on: where a source doesn't give a
value directly, or where the team picked one option over another. Use this list to write the final
report's assumptions/limitations section, and to know which assumptions each scenario or sensitivity run
tests.

Last updated: 2026-09-27

Numeric parameters (values, units, low/high range, source) belong in `data/processed/parameters.csv`
(`CLAUDE.md` rule 7; not built yet, `PROMPTS.md` Prompt 4/7 create it). This file records the reasoning
and decision status behind each choice, not the numbers themselves.

**Columns.** Affects = which sections/data/objective, with counts where the docs give them. Tested by =
the scenario/sensitivity/extension name from `docs/scenarios_and_extensions.md`, or "none" (flags an
untested assumption). Status = decided / proposed / open.
